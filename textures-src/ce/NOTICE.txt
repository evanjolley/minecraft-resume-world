Modification: grass_side.png is a derivative. Upstream ships it as a partly
transparent overlay meant to be composited onto dirt at render time. It has
been flattened onto dirt.png here so it can be used directly as an opaque
block face. That derivative is likewise CC-BY-SA-4.0.

Modification: crack.png is a derivative of the pack's crack_anylength.png.
Its RGB channels have been flattened to black while preserving the original
alpha, so it can be used as a pure alpha mask for a black crack overlay.
That derivative is likewise CC-BY-SA-4.0.
